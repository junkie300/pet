# API 참고문서 두는 곳

공공데이터포털·LOCALDATA 등에서 **로그인해야만 받을 수 있는** API 명세 문서를 둔다.

## `etl/data/` 와 다른 점

| | `etl/data/` | `etl/docs/` (여기) |
|---|---|---|
| 내용 | 원본 데이터 (법정동코드 등) | API 명세·참고문서 |
| 크기 | 크다 | 작다 |
| 재취득 | 공개 링크에서 언제든 | **로그인 + 마이페이지를 거쳐야 한다** |
| 커밋 | ❌ 제외 | ✅ **커밋한다** |

잃어버리면 D-37 상황으로 되돌아간다 — 엔드포인트를 추측으로 맞출 수 없다.

## 형식

`.xlsx` · `.pdf` · `.docx` 로 둔다. **`.hwp` 는 이 저장소의 도구로 열 수 없다** —
한글에서 `파일 > 다른 이름으로 저장 > PDF` 로 변환한 것을 함께 넣는다.
