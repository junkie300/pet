## 반드시 짚고 갈 것 3가지

**1. 좌표가 경위도가 아니다.** `CRD_INFO_X=187381.28`, `CRD_INFO_Y=441908.62` 형태의
평면직각좌표다. LOCALDATA 계열은 **EPSG:5174**(Korean 1985 / Modified Central Belt)를 쓴다.
`pyproj` 로 EPSG:4326 으로 변환해야 `places.lat/lng` 에 넣을 수 있다
(`requirements.txt` 에 이미 예고돼 있다). **변환 전에 실제 좌표로 검산할 것** —
광명시 광명동이 위도 37.4x · 경도 126.8x 근처로 나와야 한다.
`CRD_INFO_X` 가 **빈 값인 행이 있다**(예: 코어동물의료센터). 좌표 없는 행을 버리지 말고
주소는 살린다 — 지오코딩으로 나중에 채운다.

**2. 읍면동은 코드가 아니라 주소로 배정한다.** `OPN_ATMY_GRP_CD` 는 시군구(때로는 일반구)
까지만 가리킨다. 이 앱의 단위는 읍면동이므로 **`LOTNO_ADDR` 을 파싱**해야 한다.
D-31 에서 TourAPI 를 두고 내린 것과 같은 판단이다.
⚠️ 주소는 **새 체계**로 온다 — 응답에 `전북특별자치도`, `경기도 화성시 동탄구`(2026 신설)가
그대로 있다. 반면 `개방자치단체코드` 문서는 옛 체계다(광주·전남 분리). **둘을 섞지 말 것.**

**3. 폐업을 걸러야 한다.** `SALS_STTS_CD` 가 `01`(영업/정상)이 아닌 행은
`places.status` 를 `open` 이 아닌 값으로 넣는다. 코드표는
`개방자치단체코드_영업상태코드.xlsx` 의 `2. 영업상태코드` 시트에 있다.

| 코드 | 뜻 | `places.status` |
|---|---|---|
| `01` | 영업/정상 | `open` |
| `02` | 휴업 | `suspended` |
| `03` | 폐업 | `closed` |
| `04` | 취소/말소/만료/정지/중지 | `closed` |
| `05` | 제외/삭제/전출 | `closed` |
| `06` | 기타 | `closed` |

`plan.md` 1단계 완료 기준에 "폐업 업소가 표시되지 않는다"가 있다.
