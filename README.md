# 미리펫

반려동물과 낯선 지역에 갈 때, 그 지역의 동물병원·미용·동반 식당·관광지를
**읍면동 단위로 한 화면에서 미리 확인하는** 안드로이드 앱.

> 이름이 제품의 한 줄 정의다 — **"미리"** 확인한다 (D-24·D-43).
> `applicationId` 는 이름과 무관한 값으로 남겨 둔다. 이름은 언제든 바꿀 수 있어야 한다 (D-41).

| 앱이 켜지자마자 죽고 `UnsatisfiedLinkError: libK3fAndroid.so not found` | 카카오맵 SDK 는 **arm64-v8a·armeabi-v7a 만** 배포한다. x86_64 에뮬레이터에 맞는 라이브러리가 없다 → `KakaoMapSdk.init` 을 `runCatching` 으로 감싸 **지도 탭만** 안내로 바꿨다. 지도 하나로 앱 전체가 못 켜지면 안 된다 (D-71) |
| 묶음(클러스터)을 눌러도 **갈라지지 않음** | `fitMapPoints` 는 점들이 화면에 **들어오게만** 한다 — 방금 다 보이던 묶음을 누른 것이라 배율이 그대로고 같은 원이 다시 그려진다 → 갈라지는 배율을 `MapClustering.zoomToSplit` 이 계산해 `newCenterPosition` 으로 간다 (D-83) |
| 칩의 글자가 **한 자씩 세로로** 쌓임 | `Row` 에 칩이 한 줄을 넘게 들어갔다. 마지막 칩이 남은 폭으로 눌린다 → 길이를 우리가 정하지 못하는 목록(지역명 등)은 **`FlowRow`** 로 줄을 바꾼다 (D-84) |
| 런처 아이콘의 위아래가 **잘림** | 적응형 아이콘의 안전영역은 가시영역(72dp)이 아니라 **중앙 66dp 원**이다. 마스크가 제조사마다 달라서 가장 좁은 원을 기준으로 맞춰야 한다 → `tools/make_launcher_icon.py` 가 최대 **반지름**을 재서 맞춘다 (D-77) |
| 아이콘의 **핀이 안 보임** | 배경색이 임시 아이콘 시절의 딥그린(`ic_launcher_background`)인데 전경 핀도 딥그린이 됐다 → 배경은 앱 바탕과 같은 웜 크림 `#FAF7F0` 이다 (D-77) |
| release APK 가 5.79MB → 43.8MB | 지도 네이티브 라이브러리 두 벌이다(arm64 18.1MB + v7a 15.9MB). **유니버설 APK 숫자다** — Play 는 AAB 를 ABI 별로 쪼개므로 기기당 23~26MB 다 (D-72) |
| PostgREST 조회가 1,000행에서 잘림 | 읍면동은 5,067행이다. `.range()` 로 페이지네이션해야 한다 (`mapping.select_all`) |

> ⚠️ **D-29·D-30 은 앞으로 가장 조심할 지점이다.** 공공 API 들이 행정구역 개편을 **같은 속도로
> 반영하지 않는다.** 2026-09-02 실측 기준 APMS 는 반영했고 **TourAPI 만 옛 체계**다.
> 그래서 `전남광주통합특별시 ↔ 광주+전남`, `제물포구·영종구 ↔ 중구` 같은 1:N 구간이 생긴다.
> 단순 1:1 조인은 데이터를 절반 날린다. → `mapping.py` 의 예외표 두 개로 처리한다.
>
> ⚠️ **D-31.** TourAPI 는 **코드만 옛 체계이고 주소(`addr1`)는 새 체계**다.
> 5단계에서 TourAPI POI 를 읍면동에 배정할 때는 **코드가 아니라 주소 문자열을 파싱**해야 한다.
